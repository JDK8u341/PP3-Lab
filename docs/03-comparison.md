# R05、R06、R09：比较、编码与比较排序

## 自然数大小比较

先用地址等值判断 a=b，相等时直接得到等于标志。否则复制到 p、q，同时递减，直到其中一个为零。

每轮后 `p=a-k,q=b-k`。循环仅在两者都非零时进入，所以不会把非负槽减成负数。a≠b 时，停止后恰好一个仍为正：p 正说明 a>b，否则 a<b。原输入未修改，输出 lt、eq、gt 恰好一个为 1。

相等分支的分派数有固定上界；不等分支为 `O(min(a,b)+1)`。这已免去逐值分类，却仍不是按整数位数高效的顺序比较。不能把等值的地址技巧误当成大小关系的地址排序操作，PP3 没有直接暴露字典键的有序遍历。

## 有符号编码

一个有符号值用 `(s,m)` 表示，其中 s∈{0,1}、m≥0；数学值为 `(-1)^s*m`。零的符号自动规范化为 0。

- 符号不同，负数小于非负数。
- 都非负，直接比较幅值。
- 都为负，反转幅值的大小结果。

算法不需要为 -1、-2 等每个保留地址写输入分支，因为变量从不保存裸负值。`signed-comparison` 示例要求已经编码的四行输入，不声称完成了任意裸有符号 `@input` 到该编码的无枚举转换。那个问题仍留在后续研究中。

测试对 [-8,8]² 的全部 289 个数学整数对进行编码后比较，同时验证负零。测试端生成编码是测试夹具；示例协议本身就是编码输入，不能把它宣传成接收两行裸负数的完整输入器。

## 比较排序

`comparison-sort` 输入自然数数量 n，之后 n 行自然数。数据写入负地址带。两个游标分别读取相邻项，调用上述比较；仅当左项大于右项时交换。每一趟结束，当前未排序前缀的最大值到达右端，再缩短前缀。

循环不变量：外层每完成一趟，右侧后缀已非降序，并且不小于左侧任何元素。最终全部非降序。每次交换保留两个数的多重集，所以输出与输入长度和重复次数相同。

严格大于才交换，不交换相等项。源码只输出数值，未实现带身份标签的记录接口；“稳定”的论证适用于相邻交换规则本身，当前测试没有给外部记录标签验证稳定性。

比较次数为 `n(n-1)/2`，加上 n 个空或缩短轮次。若最大数为 M，简单基本操作上界为 `O(n²(M+1)+n)`；实际相等对会快速返回。它适用于任何自然数域，不建立 256 个或按最大值展开的桶，但不适合大量巨大且接近的不等数。

本项目保留这一清晰基线来验证通用比较和游标组合，暂不以代码 golf 或性能最优为目标。
