# R07、R08：交错数据带与按位计算

## 两条带的布局

保留零锚点 -1、-2，普通槽位于 -3..-(N+2)。取 `B=N+3`，两条带分别是：

```text
A[i] 位于 -B-2i
B[i] 位于 -B-2i-1
```

普通槽和数据带不相交。两条带相交将要求 `2(j-i)=1`，不可能成立；同一条带可以由多个不同名称的游标共享。

数据非负，游标保存负地址。因为数据值可能指向正地址标记，单个元素地址到 0 最多是 `元素→数据→零锚点→0` 三步；游标槽到 0 最多四步。

## 为什么游标深度是 5

先清 0 槽，从游标 P 用 `^5`，经过至多四次跳转到 0，令 0 槽指向 P；建立 P 自环。新的数据地址 X 最多三步到 0，再一步到 P，其余跳转留在 P。因此 `^5` 可安全重置或移动游标。

每次前进让地址减二，后退加二，均为常量条指令。只能在调用方已证明的边界内后退，宏不会自动阻止越过带首端；越界可能进入普通变量区，属于违反前置条件。

写元素时该元素本身是目标，以 h=2 的 `^4` 自环宏处理非负新值。游标操作和元素写入需要不同深度，不能随意互换。

## 为什么换数据表示

把整数 M 存在一个自然数槽里，然后用 M 次自增完成工作，复杂度可能随数值而非位数增长。这里将输入直接保存为二进制位串，任何槽都只需承载 0/1，避免先把长串转成巨大的单槽数值。

`binary-add` 读取位宽 w 和两个恰好 w 位的二进制文本行。两条带从高位到低位存储。读取完成后游标都在尾后一格；每轮向前退一格，从最低位开始处理。

## 全加器

设输入位 a、b、旧进位 c 都是 0/1，计算：

```text
t = a xor b
sum = t xor c
carry_next = (a and b) or (c and t)
```

实现只有布尔分支与复制，不枚举整数 a+b+c 的所有取值，也没有按输入整数的全部可能值展开程序。

完成 i 个低位后，A 带已覆盖的 i 位是正确的低 i 位和，进位携带剩余高位贡献，未处理高位仍保留原输入。全加器等式保持该不变量。处理 w 位后，先输出最终进位，再顺序输出 A 带 w 个和位，共 w+1 位及 LF。

固定宽度输出允许前导零；w=0 时输入两条空行，输出 `0\n`。定义域要求位行只包含 0/1 且长度准确。当前示例不校验非法字符或错误行宽，不为这些输入规定错误结果。

## 复杂度与测量

每位加载、全加器和回放都是固定上界的基本操作，故按 handler 分派次数为 O(w+1)，显式位存储也为 O(w)。运行器自己的文本缓冲和字典条目是另外的宿主开销。

对 A 全为 1、B 只有最低位为 1 的跨全长进位样例，8..1024 位实测为 `453w+100` 次分派，1024 位为 463972。这个精确线性公式只针对这类数据；其他位模式会走不同布尔分支，但仍有线性上界。

验证包含 0..2 位全部输入组合、多个固定种子随机长串、512 和 1024 位、全长进位，以及三个位宽的等间距成本差相等检查。没有宣称已经实现二进制乘法、除法或完整大整数库。
