# 示例输入输出与定义域

每个 `.pp3` 都是完整可执行的纯 DSL。可使用 `python tools/run.py 示例名`，也可以直接用标准 IRBuilder 和禁用直接寻址的 Runtime 加载。

每次运行使用新的 Runtime。以下定义域是宏正确性的前置条件，不为越界输入承诺 ERROR 输出。整数行由原版 `@input` 解析，保留其异常和语法。EOF 原样传播。示例使用的负号输出文字和内部负地址不等于允许在普通数据槽中存裸负数。

## graph-write

输入两行自然数：集合键 k 和数据 v。插入 k 后，将 v 写入普通槽、自增再自减，输出原 v 和集合成员标志 1，各占一行。

```text
输入：
6
7

输出：
7
1
```

数据值 7 正好是键 6 的标记地址。这展示正地址标记存在时，统一图高写宏仍可工作。

## equality

输入两行自然数；相等输出 `1\n`，否则 `0\n`。支持多位大整数的原因是地址标记，不是展开输入范围。

```text
输入：
999999
1000000

输出：
0
```

## sparse-set

输入自然数 n，之后 n 行自然数键；再输入自然数 q，之后 q 行查询键。每个查询输出成员标志和 LF。重复插入无额外效果。

精确样例见 [cases.json](cases.json)，包括零键和超过字节范围的键。删除宏由独立测试验证；本示例只演示插入与查询，没有命令解释器。

## comparison

输入两行自然数，输出三行 lt、eq、gt 标志，恰好一个为 1。顺序比较会在不等时做同步抵消，因此巨大接近但不等的数可能很慢。

## signed-comparison

按四行输入 `符号A、幅值A、符号B、幅值B`，符号为 0 或 1，幅值为自然数。0 表示非负，1 表示负。输出三行 lt、eq、gt。

```text
输入：
1
5
1
2

输出：
1
0
0
```

即比较 -5 和 -2。负零自动等价于零。此接口不接受两行裸负数，明确把编码与比较分开。

## comparison-sort

输入自然数 n，之后 n 行自然数，按非降序逐项输出，每项 LF。支持超过 255 的值，n=0 不输出。

```text
输入：
6
5000
0
256
2
5000
1

输出：
0
1
2
256
5000
5000
```

这是相邻比较交换排序；没有按值域建立桶。排序性能受到现有大小比较成本限制。

## binary-add

输入自然数位宽 w，随后两行各含恰好 w 个 ASCII 0/1 字符并以 LF 结束。输出恰好 w+1 个二进制位，再输出 LF，允许前导零。w=0 时两行为空。

```text
输入：
4
1111
0001

输出：
10000
```

程序逐位读取、逐位计算，不把整个位串转为单槽自然数。它直接消费每个位行后的一个 LF；如果输入位数、字符或分隔不符合约定，当前示例不校验，也不承诺结果或终止性。
